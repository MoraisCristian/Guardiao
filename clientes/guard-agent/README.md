# Guardian Agent

This is a modular security agent for the Guardian platform. It provides monitoring and security features through OSSEC and PSAD integration.

## Features

- Automatic registration with Guardian server
- OSSEC integration for host-based intrusion detection
- PSAD integration for network intrusion detection
- Software inventory collection
- System information reporting
- Vulnerability scanning
- Remote script execution
